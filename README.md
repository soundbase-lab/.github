# SoundBase Lab

Open-source plugins and applications that extend [SoundBase](https://soundbase.app) — RF coordination and frequency management for live production.

This organization is the public home for community and verified work that plugs into SoundBase or builds on its APIs. Fork a repo, open a PR, ship a plugin for new hardware, or list a standalone app so every SoundBase user can find it.

**[Browse the Lab](https://lab.soundbase.app)** · **[Create a plugin](https://lab.soundbase.app/create)** · **[Submit a listing](https://lab.soundbase.app/submit)** · **[Docs](https://docs.soundbase.app)**

---

### What lives here

| Kind | What it is |
| --- | --- |
| **Plugins** | Small services that run inside SoundBase Desktop. Authors write device logic; SoundBase draws Live Scan, the device picker, and the knobs. Spectrum analyzers first — more device classes on the way. |
| **Applications** | Standalone open-source software built on the [SoundBase Cloud API](https://soundbase.app/lab/cloud-api). The Lab lists them; users bring their own Pro API key. |

Repositories here are meant to be forked, collaborated on, and released on their own cadence. A plugin update never waits for a SoundBase release.

---

### Getting started as a creator

1. **Start from a template** (or fork an existing plugin) and implement your device or app.
2. **Test it** under SoundBase Desktop — plugins show up in Settings → Plugins and in the live-scan picker.
3. **List it** at [lab.soundbase.app/submit](https://lab.soundbase.app/submit). Submissions are reviewed before they appear in the Lab.
4. **Collaborate** — open issues and pull requests on the repos here. Verified listings may be transferred or forked into this organization and co-maintained.

The Lab itself is a **hub, not a store**. Listings point at repositories and websites. Creators market and license their own work.

---

### Using a plugin as a SoundBase user

1. Browse [lab.soundbase.app](https://lab.soundbase.app/browse?type=plugin).
2. Sign in with any SoundBase account and **add** the plugin to your account.
3. It appears in SoundBase Desktop under **Settings → Plugins** — update or remove it there.

Code travels from GitHub to Desktop. The Lab stores the listing and the account link, not the plugin files.

---

### Contributing

- Prefer small, focused PRs with a clear description of the hardware or workflow you are enabling.
- Keep plugins on the published contract — unknown modules and forward-compatible manifests are expected.
- Be respectful in issues and discussions. Treat this organization like a shared shop floor: leave it better than you found it.

Questions about listing, verification, or the plugin contract: start at [lab.soundbase.app/create](https://lab.soundbase.app/create) or open an issue on the relevant repository.
